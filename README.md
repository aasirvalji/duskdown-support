# DuskDown support website

Public support, privacy policy, and product information for DuskDown, a private iPhone app for reviewing reported evening activity and morning pickup.

Support: aasir.valji@hotmail.com

This repository contains only the static website. The pages use no analytics scripts or third-party fonts. GitHub Pages publishes the root of the main branch.

DuskDown reports phone inactivity, not sleep. Missing Screen Time hours remain unknown.
